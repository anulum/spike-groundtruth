# Governance

Miroslav Šotek (ANULUM) owns this project and its release decisions. Arcane Sapience contributes engineering work under that authority. Technical changes require source review, actual validation and a scoped local commit before publication is considered.

A repository validation result establishes only its named infrastructure scope. Domain qualification, trust policy, signing authority, external schema registration and scientific claims each require their own evidence and review. An inventory entry cannot establish these facts by declaration.

Remote creation, repository settings, publication, package registration, releases, deployments and uploads require explicit owner authority. No workflow may grant itself such authority. Security reports use the private contact in [SECURITY](SECURITY.md). Ownership or licence questions go to protoscience@anulum.li.
