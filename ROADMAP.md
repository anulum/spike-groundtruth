# Roadmap

Implemented repository tooling validates metadata, source provenance, workflows, dependencies, documentation and inventory, with a fixed orchestration profile. Those operations do not generate or qualify stimulus data.

Planned generation covers geometry, texture and occlusion for event vision; tones, linear chirps and envelopes for audio; and steps, ramps and disturbances for scalar industrial-control models. Each method retains complete parameters, exact time grids, model truth, effective input, finite encoding and both declared noise branches. Intended public operations are list, generate, regenerate and verify; these stimulus operations are not currently available.

Domain acceptance requires a closed protocol, independently qualified numeric and random-source behaviour, original positive and adverse cases, actual container writing and codec-aware quality, a separate oracle and genuine fresh whole-byte regeneration. Nonvisual channel semantics remain distinct from image geometry. No unknown quality result becomes a positive result because regeneration matches.

The sole owning toolkit supplies common sealing. Real library consumers and the Studio integration must preserve exact method and source versions, truth, quality and regeneration outcomes. Every implemented counterpart needs native strict checks, meaningful coverage, documentation and measured comparison benchmarks.
