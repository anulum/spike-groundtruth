# Architecture

The current executable surface is local repository validation tooling under tools/groundtruth_validation. Fixed scripts validate metadata, source, workflow policy, development dependencies, rendered documentation and inventory, and orchestrate explicit validation profiles. Received files cannot choose executable code or a weaker schema. Structured reports describe only the named infrastructure operation.

Metadata acceptance precedes capability generation. The independently pinned closed schema binds repository identity, current governance profile, interpreter and raw development lock. Generation writes accepted metadata to a new exclusive output; verification never repairs an existing inventory.

Planned stimulus generation belongs to a separate future library and CLI. Its three domains are event vision, audio and industrial control, with nine fixed methods and explicit noise branches. Complete declared model truth precedes encoding. Independent analytic truth checking and fresh whole-byte regeneration are separate obligations.

SPIKE-LOG owns container serialisation, SPIKE-QUALITY-GATE owns quality interpretation, and EVIDENCE-MANIFEST-TOOLKIT owns common sealing and trust. These are planned integrations, not installed dependencies or qualified capabilities in this source tree. Synthetic truth describes the chosen model; it establishes no physical labels.
