# Support

Contact protoscience@anulum.li or https://www.anulum.li for project questions, commercial licensing and contribution coordination. Include the exact source revision, Python version, command and safe structured report when asking about validation.

Current support covers repository validation tooling only. Stimulus generation, independent truth checking, quality integration and regeneration remain planned. No hosted issue tracker, discussion board, package index release or support service is implied by this local repository. Use the private [security route](SECURITY.md) for vulnerabilities and the [contribution guide](CONTRIBUTING.md) for proposed changes.
